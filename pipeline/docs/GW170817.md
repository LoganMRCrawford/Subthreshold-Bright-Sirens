# Obtain the reviewed GW170817 calibration cache

This procedure works from the maintained repository **without the local
SFM/LC archives**. It reproduces the strain sample values used by the
reviewed historical cache, while leaving all existing inputs untouched.

## One explicit acquisition command

In the pipeline host or search environment, from the repository root:

```bash
python pipeline/run.py data gw170817 \
  --output pipeline/work/strain/GRB170817529
```

Use a **fresh output directory**. The command downloads about 185 MB in
three sequential bounded transfers and retains the original public HDF
files alongside the new cache. Allow roughly 350 MB of disk space. It does
not import JAX, fit a PSD, evaluate a likelihood or submit a job.

For offline use, first transfer the three exact released files listed in
[the release manifest](../lc_pipeline/releases/gw170817-v2.json) to a local
directory. This option performs no network request:

```bash
python pipeline/run.py data gw170817 \
  --source-dir /path/to/released-hdf-files \
  --output pipeline/work/strain/GRB170817529
```

The source directory contains the full official release files, **not**
three previously cropped pipeline caches. The manifest lists their exact
names, sizes, URLs and SHA256 hashes. A wrong/newer release is rejected;
there is no fallback to generic GWOSC run data.

## What is pinned and checked

- Release: **O1_O2-Preliminary / GW170817 v2**, cleaned
  **LOSC_CLN_4_V1**, H1/L1/V1, 4096 Hz, 2048 seconds starting at
  GPS 1187007040. This is intentionally not the later v3 R1 product.
- Original public HDF bytes: complete-file size and SHA256 must match the
  recorded review. URLs are version-specific and transfers remain HTTPS.
- Cache: 4,784,128 samples per detector, with sample epoch
  GPS 1187007716.4746094. The contiguous little-endian float64 sample hashes
  must match the previously verified cache, and HDF write/read must preserve
  the arrays and sample epoch exactly.
- Metadata: the gamma trigger is GPS 1187008884.474624; the requested
  128 s on-source, 1024 s earlier PSD context and 16 s gap are recorded
  independently of sample-grid rounding. No interpolation is applied to
  conceal that distinction.
- Publication: all three detectors, metadata and standard data-window
  inspection must succeed before the final event directory appears.

GWpy may print an end-of-crop warning for the fractional trigger versus the
last stored sample. The command still requires the exact on-source/context
sample counts and grid tolerances; the warning is not silently treated as
permission to accept a truncated window.

The generated event directory contains the three sampler-compatible HDF
files, primitive metadata, a release-manifest copy, original released HDFs
and a data-provenance record. The source review on 1 November 2026 compared
every cached sample to this public release. The maintained manifest retains
that audit's identity without requiring a private path or importing old code.

**New HDF files and metadata need not have the same serialization hashes as
the old cache, even when sample values match.** Use this for new calibration
bundles, never to replace inputs in an existing frozen/resumable campaign.
Recompute/import explicitly compatible PSDs and retain a matched GW170817
whole-sky/map pair when preparing a new route.

## Failures and repeat attempts

An exclusive acquisition claim prevents concurrent or accidental duplicate
runs for one target. A failed transfer/validation leaves a hidden staging
directory with diagnostics and **no published event cache**. Review the
reported failure first; use a different parent output directory for a new
attempt rather than deleting claims or overwriting partial data blindly.
The three-detector command can also be rerun against locally transferred,
checksum-verified release files to avoid an unreliable network.

The real public route was exercised successfully for all three detectors
on 10 November 2026, including exact comparison to the historical cache.
One earlier transfer was interrupted by the remote server; its failure was
retained and a fresh attempt succeeded. Offline regression tests exercise
checksum, size, grid, sample, full-network and duplicate-run safeguards.

## Scientific boundary

This fixes **release acquisition and reproducible input preparation**. It
does not independently certify the published cleaning/glitch subtraction,
resolve the 4-kHz release's high-frequency conditioning, establish a new
PSD estimator's accuracy or demonstrate sampler convergence. No extra
glitch removal, filtering or resampling is performed. See the
[scientific limitations](SCIENTIFIC_LIMITS.md) for what still requires tests.
